# Institutional marks

Affiliation logos for the authors section, shown at full colour and a
uniform display height.

Files `NN-slug.webp` are ordered by the author superscript number in
`index.html`. Each is trimmed to its visible bounding box and exported at
72 px height (WebP, quality 92), then constrained in CSS.

Source: Wikimedia Commons, resolved from each institution's Wikidata
"logo image" (P154) claim, except Cornell University, Georgia Tech and
Notre Dame, which come from the corresponding Commons file found by
search. These are the institutions' own marks and remain their
trademarks; they are used here to identify an author's affiliation.

Four affiliations have no freely licensed mark on Commons and are set as
typeset text instead: University of Georgia, University of Toronto,
Tundra Solutions and MatrAIx. Replace the text cells with an image only
if the institution supplies its own file.
