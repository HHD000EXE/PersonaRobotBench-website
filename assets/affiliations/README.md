# Institutional marks

Affiliation logos for the authors section, shown at full colour and a
uniform display height.

Files `NN-slug.webp` are ordered by the author superscript number in
`index.html`. Each is trimmed to its visible bounding box and exported at
72 px height (WebP, quality 92), then constrained in CSS.

## Sources

Marks come from the institution's own brand resources where a usable file
is published, and otherwise from its Wikidata "logo image" (P154) claim
on Wikimedia Commons (public-domain text logos).

Taken from the institution's own site:

- `01-usc.webp` — identity.usc.edu, official informal logotype
- `04-uga.webp` — brand.uga.edu, horizontal university logo
- `11-toronto.webp` — utoronto.ca theme mark, recoloured from the white
  cut to the university blue (#002A5C)
- `16-tamu.webp` — tamu.edu, primary Texas A&M University lockup
- `19-wisc.webp` — brand.wisc.edu, institutional logo

## Typeset fallbacks

Three affiliations have no freely licensed official mark, so their names
are set in type instead of using an invented or unrelated logo:

- Tundra Solutions
- University College London (the only free file is an unofficial coat of
  arms, and ucl.ac.uk refuses automated requests)
- MatrAIx

Replace a text cell with an image only if the institution supplies its
own file.

These are the institutions' own marks and remain their trademarks; they
are used here to identify an author's affiliation.
